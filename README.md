# LLM-Assisted ETL Pipeline

## Project Overview

This project focuses on the design and implementation of an ETL (Extract, Transform, Load) pipeline for e-commerce data, with LLM-assisted pipeline generation.

The project compares a manually implemented ETL pipeline with an LLM-assisted approach and evaluates their results.

## Project Structure

- `data/` – Raw e-commerce datasets
- `evaluation/` – Evaluation scripts, results, and comparison charts
- `llm_agent/` – LLM-based pipeline generation components
- `notebooks/` – Data exploration, cleaning, and ETL testing notebooks
- `reports/` – Final project report and supporting images
- `main.py` – Main project entry point
- `check_models.py` – Model checking utility
- `requirements.txt` – Python dependencies

## Main Components

### Manual ETL Pipeline
The manual pipeline performs data cleaning, transformation, and integration of the e-commerce datasets.

### LLM-Assisted Pipeline
The LLM agent generates ETL pipeline code based on the required data processing tasks.

### Evaluation
The two approaches are evaluated using factors such as:

- Data quality
- Execution time
- LLM generation time
- Development effort
- Overall pipeline performance

## Technologies Used

- Python
- Pandas
- Jupyter Notebook
- LLM-based pipeline generation
- Git & GitHub

## Dataset

The project uses the Olist Brazilian E-Commerce dataset.
